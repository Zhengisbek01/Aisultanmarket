# AisultanMarket — учёт магазина со сканером штрих-кодов

React + Vite приложение для магазина: сканирование штрих-кода товара (камера телефона),
две роли (руководитель / продавец), учёт продаж, прихода, долгов и отчётность.

## Роли

- **admin / 1234** — руководитель: видит все отчёты, товары, приход, долги
- **seller / 1111** — продавец: только сканирование и продажа

Логины/пароли можно поменять в коде `src/store.js` (функция `getUsers`) до первого запуска,
либо через консоль браузера — данные хранятся в `localStorage` устройства.

## Как это работает

- Товары хранятся локально в браузере (localStorage), у каждого товара: штрих-код, название,
  цена продажи, закупочная цена (для расчёта прибыли), вес/объём, остаток на складе.
- Продавец сканирует штрих-код камерой → видит цену и вес → оформляет продажу → товар
  списывается со склада.
- Руководитель заносит приход (закупку) → товар зачисляется на склад.
- Руководитель фиксирует долги (нам должны / мы должны).
- Вкладка «Отчёт» считает: доход, приход, себестоимость проданного, чистую прибыль, долги —
  за любой период.

⚠️ Данные хранятся в браузере устройства, на котором запущено приложение (не в облаке).
Если нужно, чтобы товары/отчёты были общими для нескольких телефонов одновременно —
понадобится добавить бэкенд (например, Firebase или собственный API) — могу сделать отдельно.

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой на Vercel

1. Залить папку в GitHub-репозиторий
2. На vercel.com → New Project → выбрать репозиторий
3. Framework Preset: **Vite** (или "Other", если Vite не определится автоматически)
4. Build command: `npm run build`, Output directory: `dist`
5. Deploy

Камера работает только по HTTPS — Vercel это обеспечивает автоматически.
На телефоне откройте сайт и разрешите доступ к камере при первом сканировании.
